# 1. Record architecture decisions

## Status

Accepted

## Context

We need to record the architectural decisions made on this project so future
readers (including yourself in six months) understand why things are the way
they are.

## Decision

Use one Markdown file per decision in `docs/decisions/`, numbered sequentially:
`NNNN-title-in-kebab-case.md`. Each file covers status, context, decision, and
consequences.

## Consequences

Decisions are versioned alongside the code and reviewable in pull requests.
